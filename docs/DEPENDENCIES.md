# 依赖登记（DEPENDENCIES）

> 本文件登记**项目实际声明并锁定**的依赖。库的来源地址、许可证初判与安装形态见 [`ENVIRONMENT.md`](ENVIRONMENT.md)（那是一份只读清单）。
> 本文件当前**为空**：仓库还没有 `pyproject.toml` / `package.json`，因此没有任何依赖被真正引入。

## 1. 登记规则

新增依赖前必须完成（顺序不可颠倒）：

1. 查 [`ARCHITECTURE.md`](ARCHITECTURE.md) §9 复用清单，确认没有现成方案。
2. 核对候选库：维护状态、许可证、**Windows 预编译 wheel**、与锁定版本兼容性。
3. 优先纯 Python / 有 wheel 的方案；需要本机编译的必须写明替代方案。
4. 锁定精确版本；不写 `^`/`~` 浮动范围（由 lockfile 兜底，但声明也写精确值）。
5. 在本文件表格中登记一行。
6. 至少加一个"导入/使用"冒烟测试（`tests/unit/test_deps.py`）。
7. 不引入两个功能重复的库（例如同时装两个 GeoJSON 模型库）。

**自研**引擎/编辑器/切片/表单/搜索之前，必须先写 ADR（`DECISIONS.md`），列出候选与不采用原因。

## 6. 变更流程

- **新增**：按 §1 七步走；同一任务里同时更新本表、`uv.lock`/`package-lock.json`、`ENVIRONMENT.md`（若清单缺失）、`ATTRIBUTION.md`（若含资产）。
- **升级**：单独任务；附 `check --full` 输出；说明行为变化与回归风险；不得与功能改动混在同一提交。
- **移除**：删除代码引用 → 删表行 → 重新 `uv lock` / `npm install` → 跑全量检查。
- **许可证冲突**（如引入 GPL 库）：必须停下询问人类，不得默认接受。

## 7. 已知的许可证红线

- QGIS（GPL）只能作为**外部独立工具**，不得链接进 Python 包，不得随分发物捆绑。
- 不引入 AGPL 依赖到运行时路径。
- 字体/图标许可证必须允许再分发；不允许的资产只可本地使用并在 `ATTRIBUTION.md` 标注。
